# Bowl & Hearth — Local Catering & Cloud Kitchen

Pure HTML5 + CSS3 + JavaScript + Tailwind CSS. No React, Vite or React Router.

## Structure

- `index.html` — only HTML file in the project root.
- `assets/pages/` — all internal pages.
- `assets/css/` — custom CSS.
- `assets/js/` — shared header/footer and interactions.

## Run

Open `index.html` in a browser. Tailwind is loaded through its CDN, so an internet connection is needed for the utility classes and Google Fonts.

## Pages

Home, Home 2, About, Services, Service Details, Menu, Cloud Kitchen, Bulk Orders, FAQ, Blog, Blog Details, Contact, Pricing, Login, Register, Admin Dashboard, 404 and Coming Soon.

The admin dashboard is a UI template only; no backend/authentication/database is connected.
